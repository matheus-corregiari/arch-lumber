# Changelog - 1.3.0

## Motivation

Modernize the build toolchain and make the release workflow explicit without changing the public
logging API or the published target surface.

## Notable changes

- upgraded the Gradle wrapper, Kotlin, Android plugin, Detekt, and Kover tooling
- raised Android `compileSdk` and build tools to API `37`, while retaining `minSdk 20`
- restricted the pull-request flow: work branches target `release/*` or `hotfix/*`; only those
  branches can target `master`
- added missing release changelogs and linked every release page in the MkDocs navigation
- removed the repository Dependabot configuration

## Compatibility notes

- The public `Lumber`, `Lumber.Oak`, `Lumber.Level`, and `DebugOak` API remains unchanged.
- Published targets remain Android, JVM, Apple, JS, and WasmJS.
- Android consumers retain `minSdk 20`; projects building this source should use the listed
  Gradle, Kotlin, and Android toolchain versions.
