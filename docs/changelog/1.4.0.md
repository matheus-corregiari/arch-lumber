# 1.4.0

Status: planned; published only after the release tag is created.

## Changes

- Replace separate CI workflows with one shared contract for all pull requests and master.
- Run assemble, tests and enforced coverage together; keep Static Analysis, Docs and CodeQL gates.
- Validate next major/minor releases and patch hotfixes against remote tags before merging.
- Create an annotated tag only after master CI; publish both package registries from the tag.
- Verify publication provenance and skipped destinations during recovery.
- Refresh Java/Python/checkout Actions and use one Gradle cache owner.

No public API changes are intended. Coverage limits are explicit per project.
