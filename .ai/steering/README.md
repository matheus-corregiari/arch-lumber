# Project Steering

These notes capture the current implementation patterns in `arch-lumber` so future changes stay aligned with the library's design.

Files:
- `architecture.md`: source-set boundaries, module layout, and platform strategy
- `code-patterns.md`: API and implementation rules for `Lumber`, `Oak`, and `DebugOak`
- `documentation.md`: KDoc, README, published docs, and changelog maintenance rules
- `testing.md`: test structure and regression expectations

Scope:
- describe the patterns already present in the repository
- guide future edits without replacing the public docs in `docs/`
- prefer add-only clarification unless the repository patterns intentionally change
