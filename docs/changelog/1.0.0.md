# Changelog - 1.0.0

**Release Date:** 2026-01-25

Initial stable release of Lumber.

## Highlights

- core logging API inspired by Timber
- pluggable `Oak` architecture
- thread-safe one-shot tag and limit state
- multiplatform support for Android, JVM, Apple, JS, and WasmJS
- message splitting and simple `%s` / `%d` formatting

## Tooling

- GitHub Actions release flow
- Detekt, ktlint, and Kover integration
- Maven Central publishing via `vanniktech-publish`
