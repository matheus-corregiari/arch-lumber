# 1.4.4

Maintenance changes based on tag `1.4.3`.

## Changes

- Create the GitHub Release with its versioned release notes after Maven Central and GitHub Packages publication tasks succeed, without waiting for public artifact availability.
- Explicitly retain Vanniktech's `DeploymentValidation.VALIDATED` policy. Central validation failures still fail publication; public download availability and search indexing can follow later.
- Generate the publication manifest and check existing POMs only during manual recovery. Preserve checks for destinations omitted from recovery, including both registries in `release-only` mode.
- Remove the unused post-publication polling mode and add regression tests for recovery destination selection and missing publications.

## Compatibility

No library API, runtime behavior, dependency version or supported-target changes. Release tag provenance and master CI gates remain required.
