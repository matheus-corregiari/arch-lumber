# 📦 Changelog - 1.0.2

**Release Date:** 2026-02-09

This release focuses on significantly improving the library's documentation, developer experience, and multiplatform consistency.

### 📖 Documentation & DX
- **Full KDoc Overhaul**: Complete rewrite of KDocs for `Lumber`, `Oak`, `DebugOak`, and internal utilities, providing clear examples and best practices.
- **Improved README**: A more professional and informative landing page with quick-start guides, platform support details, and a contributor's guide.
- **Detailed Platform Docs**: Specific documentation for each target platform implementation of `DebugOak`.
- **Changelog System**: Established a structured changelog directory within `/docs` for better history tracking.

### 🧹 Refactoring & Improvements
- **Multiplatform Consistency**: Refined `DebugOak` implementations to ensure a consistent logging experience across all supported targets.
- **Internal Utilities**: Added documentation and small refinements to internal string formatting and camel-casing logic.
- **Build Configuration**: Updated project metadata and documentation links.

### 🛠️ Tooling
- **JVM Toolchain**: Added `gradle-daemon-jvm.properties` and Foojay plugin for more reliable JDK management.
